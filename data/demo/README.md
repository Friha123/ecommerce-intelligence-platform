# Jeu de démonstration (synthétique)

Ces fichiers permettent à l'application de **démarrer sans données réelles** (tests, CI, première prise en main).

- Ils ont été produits en exécutant les notebooks `05a`, `05b`, `05c` sur un **jeu de données synthétique au format Olist**.
- Les chiffres n'ont **aucune valeur analytique** : l'application affiche un bandeau « Mode démonstration » tant qu'ils sont utilisés.
- Dès que `data/app/` contient les vraies données (voir `docs/DEPLOYMENT.md`), l'application les utilise automatiquement.
